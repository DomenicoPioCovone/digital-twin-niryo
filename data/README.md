# Dati racolti durante le misurazioni

I dati presenti nei file.csv sono dati dalle tre misurazioni effettuate durante la presa e lo sposatmento di "mattoncini colorati".

## Misurazioni e rilevazione delle anomalie



### Funzionamento Nominale
- I dati registrati nel file FunzionamentoNormaleCompleto.csv sono quelli relativi a un corretto funzionamento del braccio robotico

### Anomalia dimensionale
- I dati registrati nel file AnomaliMattoneDoppio.csv sono i dati relativi all' anomalia presentatasi con la presenza di un mattoncino di dimensioni maggiori
- Vedi video allegato

### Anomalia Posizionale
- i dati registrati nel file AnomaliaNonRilevato.csv sono i dati relativi all' anomalia presentatasi durante il rilevamento di un mattoncino di colore verde posizionato sulla parte più esterna della superfice di rilevamento
